    9. 에이전트·토큰 경제: 생활 속 에이전트와 토큰 물량·가격·과금·결제

    자료: Visa·Mastercard·Google AP2/UCP 문서, Adobe·eMarketer 리테일 데이터, Menlo(OpenRouter), McKinsey·Morgan Stanley 전망(요약 기준), Unit 42·Guardio의 에이전트 사기 분석, 한국은행, 과기정통부. 원문은 PDF/socioeconomic/*_agenteconomy_*에 있습니다. 일부 수치는 검색 요약 기준이라 인용 전에 원문을 확인해야 합니다.

    9.1 2026: 탐색은 넓게, 구매는 좁게

    • 발견 단계는 이미 대중화됐습니다.
      • 미국 쇼핑객의 47%가 쇼핑 과업 하나 이상에 AI를 씁니다(Visa).
      • 리테일 사이트로 들어오는 AI 유입은 2025년 연말 시즌에 670% 늘었고, 2026년 연말에는 다시 130% 늘 것으로 예상됩니다(Adobe).
    • 에이전트가 끝까지 결제하는 구매는 아직 작습니다.
      • 2026년 미국 에이전트 완결 구매는 약 14.4억 달러로, 연말 온라인 소비의 약 0.5%입니다(eMarketer 전망).
      • 결제 정보를 에이전트에 맡기겠다는 소비자는 15%입니다.
      • State of AI Report는 자신들의 "에이전트 결제가 온라인 판매의 5% 초과" 예측을 '빗나감'으로 채점했습니다.
    • API 트래픽은 이미 에이전트가 주도합니다. OpenRouter 토큰의 80%가 에이전트 트래픽으로, 사람 사용의 약 7배입니다(Menlo).
    • 인프라는 깔렸지만 아직 정착하지 않았습니다.
      • 결제·신원 프로토콜: Google AP2(파트너 60여 곳)와 UCP, Visa의 Trusted Agent Protocol, Mastercard Agent Pay, Stripe 결제 토큰, x402, 스테이블코인(시가총액 약 3,150억 달러)
      • 후퇴: OpenAI는 Instant Checkout을 축소했고(2026-03), Shopify는 결제를 판매자 사이트로 되돌렸습니다.
      • 첫 적용: Meta Muse가 처음으로 Link 구매보호 대상 에이전트가 됐습니다(2026-09).
    • 장기 전망치: McKinsey는 2030년 미국 B2C 에이전트 거래를 최대 1조 달러(세계 3–5조)로, Morgan Stanley는 1,900–3,850억 달러(미국 이커머스의 10–20%)로 봅니다. Gartner는 2030년 공공서비스를 막히게 하는 에이전트가 100억 개를 넘을 것이라고 경고했습니다.

    9.4 토큰 물량: 1년에 수 배에서 수십 배

    자료: Google 2026년 3분기 실적 발언, OpenRouter·Menlo Ventures 집계, Epoch AI·Artificial Analysis 가격 추세, NVIDIA FY27 3분기 실적, J.P. Morgan·Deloitte·McKinsey·Gartner·IDC, Silicon Data GPU 임대 지수, Orb 과금 분석, TRM Labs·Chainalysis·Allium 온체인 결제, IITP 2027 10대 이슈, 국내 보도(MTN·ZDNet). 원문은 PDF/socioeconomic/에 있습니다. 에이전트 확산과 생활 속 문제는 9.1–9.14절, 가격 하락 '법칙'은 4장에서 다룹니다. 랩 매출은 언론 보도(S-1/A·FT·Axios)라 출처마다 다르고, Google 2025년 토큰 수치·GENIUS Act 시행일·a16z 'LLMflation'은 기존 지식 기반이라 원문 대조가 필요합니다.

    한 줄 요약: 2027년 토큰 경제는 **'단가는 폭락, 물량은 폭증, 총지출은 증가'**하는 제번스 확장 국면입니다. 토큰이 '디지털 노동의 계량 단위'가 되면서 기업의 관심은 토큰 단가에서 **태스크 비용(과제당 토큰 × 단가)**과 **FinOps(토큰 예산·한도·텔레메트리)**로 옮겨 갑니다.

    9.5 토큰 가격: 같은 성능은 폭락, 최상위는 유지

    • 같은 성능 기준: 연 9~900배 하락(Epoch, 중앙값 약 40배)입니다. 2026년에도 AA≥30급 최저가가 8개월 만에 약 40배(GPT-5.2 $4.81 → $0.12/100만 토큰), AA≥45급이 3개월 만에 약 37배 떨어졌습니다.
    • 평균 블렌디드 단가: 폐쇄형 $0.70(-24%), 오픈소스 $0.13(약 1/3.3)입니다(100만 토큰당, 2026-09).
    • 최상위 티어는 오히려 비쌈: 프런티어 최상위 리스트가는 입력 $10/출력 $50이고, 이전 세대보다 2배 오른 사례도 있습니다. 'Pro' 티어는 출력 $180입니다. 저가 티어(출력 $0.03~1.2)와 약 1,400배 차이가 납니다.
    • 에이전트 세션 실효 단가: 캐시 읽기가 95%일 때 주력 프런티어 모델은 약 $0.70/100만 토큰입니다. 캐시가 에이전트 경제성을 좌우합니다.
    • 제번스 효과의 실측: 같은 성능 단가는 연 수십 배 떨어졌는데 미국 기업 AI 배포 지출은 5.4배(330억 → 1,768억 달러) 늘었습니다. 프런티어 모델의 지출 점유율도 35%에서 63%로 올랐습니다. 가격 하락분이 물량 폭증과 상위 모델로의 업그레이드로 상쇄됩니다.

    9.6 추론 경제: 'AI 팩토리'와 토큰당 원가

    • 추론이 컴퓨트의 중심: 추론이 전체 AI 컴퓨트의 약 2/3를 차지합니다(Deloitte, 2차 인용). 기업은 모델 구축에 1달러를 쓸 때 사용(배포)에 1.70달러를 씁니다(Menlo).
    • 공급자 실적: NVIDIA FY27 3분기 매출은 1,158억 달러(+103%)입니다. 'AI 팩토리' 레퍼런스 설계로 토큰을 '제품'으로 파는 프레임을 내세웁니다.
    • 랩 매출(보도): Anthropic 연환산 약 810억 달러(S-1/A 보도), OpenAI 500억~700억 달러(보도마다 다름). J.P. Morgan은 프런티어 랩의 매출총이익률을 60~90%로 추정합니다.
    • GPU 임대료와 손익분기: H100 네오클라우드 지수는 $2.88/시간(+44%), B200은 $6.45입니다. 1GW AI 팩토리의 손익분기 임대료가 약 $2.93이라 현재 임대료가 손익분기선에 붙어 있습니다.
    • 원가 하방 경직: HBM 부족이 최소 2027년 말까지 이어집니다(Micron·IEA). 그래서 2027년 토큰 가격 하락은 칩 원가보다 **모델 효율(MoE·증류·캐시)**에서 나옵니다.

    9.7 과금 모델: 좌석에서 '좌석 + 토큰 크레딧 + 결과'로

    • 예산 초과의 일상화: 미국 기업 AI 지출은 평균 전년의 4.7배로, 계획(1.9배)을 약 2.5배 넘었습니다. Gartner는 IT 운영 에이전트를 상한 없는 토큰 종량제로 쓰는 기업이 2027년까지 구독형 대비 비용을 50% 이상 초과한다고 보고(G00846101) 'No telemetry, no deployment'를 권고합니다.
    • 하이브리드가 주류: AI 에이전트 기업 80곳 중 95%가 구독과 사용량을 섞고, 결과 기반 과금은 3.8%입니다(Orb). 고객지원(해결 건당 과금)에서 결과 과금이 늘고 있습니다. 결과 과금은 토큰 원가가 떨어질수록 마진이 넓어져 공급자 유인이 큽니다.
    • 노동 대체 단가: 지식노동자 1시간(약 $50)은 에이전트 토큰 약 7,000만 개에 해당합니다(추정). '토큰 예산 대 인건비'가 인력계획 지표로 등장하고 있습니다.
    • FinOps 도구: 모델 라우팅(어려운 작업은 고성능, 반복 작업은 경량 모델)이 표준이 됩니다. 국내에서도 KT 토큰팩토리(2026-10-30 정식), 카페24 LLM 라우터(270여 모델)가 나왔습니다.
    • 애널리스트 원문 수치(2.3절): IDC는 기업 72%가 이미 토큰 예산을 넘겼고, 사람 검토 비용을 넣지 않으면 2028년까지 에이전트 비용이 최대 60% 과소 집계된다고 봅니다. 에이전트 행동당 비용은 약 95% 떨어지지만 연간 토큰 비용은 2030년 1,065억 달러(487배)로 늘어납니다. Gartner는 에이전틱 워크플로가 과제당 5–30배 토큰을 쓴다고 봅니다.
    • 토큰 예산의 보안 문제: 탈취 API 키로 토큰을 재판매하는 LLMJacking 시장(100만 토큰당 $0.10~25)과 '비용 소진 공격'이 등장했습니다.

    9.12 시나리오: 에이전트 경제와 토큰 경제

    시나리오 확률(±불확도) 모습

    9.13 규제 동향

    • EU: AI Act에는 에이전트 특화 조항이 없습니다. Digital Fairness Act(다크패턴·개인화 가격·구독 해지)와 DMA로 보완하는 방향입니다.
    • 미국: FTC가 단속 중이고, GENIUS Act가 스테이블코인 결제의 법적 기반을 만들었습니다. State of AI는 소비자 에이전트의 해지 요청 수용을 의무화하는 주법이 나올 것으로 예측합니다.
    • 결제망: 에이전트 거래 표시, 차지백 사유 코드, 책임 분담 규칙을 공식화할 가능성이 있습니다.
    • 한국: AI 기본법 하위법령 개정에 에이전트가 반영되고 있습니다. 기존 법률 개정을 우선한다는 원칙이 확정됐습니다(국가AI전략위). 전자금융거래법(접근매체 양도 금지·금융회사 책임)과 전자상거래법(청약철회)이 에이전트 결제와 맞지 않는 부분이 쟁점입니다.

    9.14 한국 정책 옵션과 시사점

    1. 에이전트 거래 표시·기록 의무: 위임 범위(금액·품목·기간)를 기록해 분쟁 입증자료로 씁니다.
    2. 책임 분담 기본 규칙: 승인 범위 밖 거래와 인젝션 피해는 원칙적으로 사업자가 부담하도록 전자금융거래법을 해석하거나 개정합니다.
    3. 한국형 KYA: 공동·간편인증과 연동하고 AP2·TAP와 상호운용되게 만듭니다.
    4. 전자상거래법 보완: 에이전트의 대리 청약철회·해지 수용을 의무화하고, 기계를 겨냥한 다크패턴을 금지합니다.
    5. 공정위: 에이전트의 자기우대와 유료 추천 슬롯의 표시 의무를 다룹니다.
    6. 개인정보위: 최소 권한 원칙과 로그를 요구하고, 화면 스크래핑 대신 마이데이터 API를 에이전트 공식 통로로 씁니다.
    7. 소상공인 '에이전트 레디' 지원: 표준 카탈로그와 공공 등록소를 마련합니다.
    8. 디지털 포용: 고령층 대상 사기 예방, 사람 상담 채널 유지 의무를 둡니다.
    9. 공공부문: 정부24·복지 신청에서 에이전트 대리 신청의 허용 범위와 대량 신청 방어 기준을 만듭니다.
    10. 통계 신설: 에이전트 결제 비중, 소비자 피해 상담, 차지백 사유를 분기마다 공표합니다.

    토큰 경제 한국 시사점

    1. 토큰 비용 체감: 해외 신모델 가격 인상(이전 대비 2배), '한 팀이 월 6,000만 원' 사례처럼 토큰 비용이 인건비에 근접하고 있습니다. 국내 라우팅·게이트웨이와 국산 모델·오픈웨이트 활용이 비용 방어의 핵심입니다.
    2. 통계 공백: 국가 차원의 토큰 사용량·단가 통계가 없고, 소버린 모델 API 단가도 공개 자료로 확인되지 않습니다. 국가AI컴퓨팅센터 요금도 개소(2028년 말 예정) 전까지 미정입니다.
    3. 한국어 토큰 비용: 다국어 토크나이저에서 한국어는 같은 의미의 영어보다 토큰이 많이 드는 경향이 있어 실효 비용이 높을 수 있습니다(2026 실측 미확보). 국산 토크나이저·모델의 경제적 근거가 됩니다.
    4. 원화 스테이블코인: 디지털자산기본법은 2026-11 말 현재 미통과입니다. 쟁점은 은행 지분 51% 요건과 거래소 대주주 지분 제한입니다. 원화 레일이 없으면 국내 에이전트의 기계 간 소액결제는 USDC나 간편결제·PG 토큰에 의존합니다.
    5. 공공 컴퓨팅 과금: 2027 예산 정부안의 GPU 약 1만 장과 국가AI컴퓨팅센터를 GPU시간 배분에서 토큰·API 크레딧 바우처로 확장하면 중소기업·연구자의 이용 장벽이 낮아집니다.

    9.15 국가인공지능전략위원회 안건(제안, 인공지능기본법 제8조 기준)

    • 국가 토큰 통계(2의2호 부처 조정): 국내 기업·공공의 토큰 사용량·단가·과제당 비용 통계를 과기정통부·통계청이 분담해 분기별로 공표하도록 조정합니다.
    • 공공 컴퓨팅 과금(4호 투자 방향·6호 인프라): 국가AI컴퓨팅센터와 공공 GPU 지원을 '토큰 바우처'로도 제공하는 원칙을 의결합니다.
    • 에이전트 결제 제도(5호 규제 개선): 에이전트 신원·위임·원화 스테이블코인 소액결제 규제 샌드박스와 디지털자산기본법 처리 방향을 심의합니다.
    • 한국어 토큰 효율(3호 연구개발 전략): 한국어 토크나이저·압축 등 원천기술을 국가 R&D 우선 과제로 지정합니다.
    • 보안 권고(9호 권고): 공공 기관에 API 키 탈취·비용 소진 공격 대응을 권고합니다.
    • AI 답변 광고 표시(5호 규제 개선·9호 권고): 표시광고법 심사지침에 AI 답변 속 광고의 표시·분리 기준(유료 추천과 중립 추천의 구분)을 넣도록 공정거래위원회에 권고하고, 국내 AI 검색의 출처 링크·언론사 옵트아웃 원칙을 함께 논의합니다(9.9절).
